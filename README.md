# Coding Club — AI × Zero Gravity Website

Static responsive website for Mahendra Engineering College Coding Club.

## Run
Open `index.html` directly in a browser, or use a local server:

python3 -m http.server 8000

Then visit http://localhost:8000

## Add Google Form links later
In `index.html`, replace the placeholder button behavior in the final `<script>` with the real Google Form URLs.

Assets are in `assets/`.
